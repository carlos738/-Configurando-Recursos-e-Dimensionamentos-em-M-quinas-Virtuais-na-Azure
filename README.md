# Configuração de Recursos e Dimensionamento em Máquinas Virtuais no Azure 🚀

Este documento fornece diretrizes essenciais para configurar recursos e dimensionar máquinas virtuais no Azure, otimizando desempenho e custos.

## 📌 Introdução

O Azure oferece diversas opções para configurar máquinas virtuais (VMs), permitindo ajustes em CPU, memória, armazenamento e rede. Este projeto aborda os principais aspectos para uma configuração eficiente.

## ⚙️ Principais Configurações

### 1️⃣ Escolha do Tamanho da VM
O Azure possui diferentes tamanhos de VMs para atender a variadas necessidades de processamento e armazenamento.

### 2️⃣ Armazenamento
- **HDD padrão**: Ideal para workloads menos exigentes.
- **SSD premium**: Melhor desempenho para aplicações críticas.

### 3️⃣ Rede
Configuração de redes virtuais e grupos de segurança para garantir conectividade e segurança adequadas.

### 4️⃣ Dimensionamento Automático
Os **conjuntos de dimensionamento** permitem aumentar ou diminuir automaticamente o número de instâncias conforme a demanda do sistema.

### 5️⃣ Redundância e Alta Disponibilidade
Distribuir VMs entre **zonas de disponibilidade** para garantir a resiliência do aplicativo.
